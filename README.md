# Bio-Inspired Modular Soft Snake Robot

An experimental robotics project focused on designing and developing a modular, flexible snake-inspired robot for confined-space exploration.

## Project Overview

This project explores the intersection of soft robotics, bio-inspired locomotion and mechanical engineering.
The robot is being developed using modular 3D-printed components, flexible TPU structures and independently articulated sections.

## Project Objectives

- Develop a modular mechanical architecture.
- Experiment with flexible 3D-printed TPU joints.
- Investigate snake-inspired locomotion.
- Develop obstacle-detection capabilities.
- Explore autonomous navigation in confined environments.

The project follows an iterative engineering approach:

**Design → Prototype → Test → Analyse → Improve**
